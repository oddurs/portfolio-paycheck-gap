## Outcome

PPG has one defensible meaning: it measures the cumulative divergence between the return to a representative US stock investment and the median full-time paycheck. Every choice that can change the series is written down before the production implementation begins.

## Exit criteria

- [x] The formula, population, frequency, base period, and rounding rules are fixed.
- [x] Canonical sources are reproducible and permit publication of derived data.
- [x] A reference calculation produces an inspectable historical series.
- [x] Sensitivity tests identify which methodological choices materially change the story.
- [x] The methodology states both the claims PPG supports and the claims it does not.

## 2026-09-13

All six scheduled v0.1 items are complete. Formula/scope/precision, legally usable sources, the three-quarter inspectable reference series, quantified sensitivity and revision analysis, failure policies, and versioned implementation documents have passed repository and live-source validation.
