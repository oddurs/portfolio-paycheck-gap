## Problem

A maintained benchmark needs clear ownership and review rules, especially when
outside contributions could alter historical values or public interpretation.

## Proposal

Document how to propose changes, review methodology-impacting work, report data
problems, cite the index, cut releases, and respond when the normal maintainer
is unavailable. Include a machine-readable citation file and public license.

## Acceptance criteria

- [ ] Contribution and review instructions distinguish code, data, and methodology changes.
- [ ] Citation metadata names the index, version, maintainers, repository, and release artifact.
- [ ] Code, documentation, and derived-data licenses are explicit and compatible with sources.
- [ ] Release ownership, required checks, and recovery steps are documented.
- [ ] A public channel exists for reporting suspected data or methodology errors.
