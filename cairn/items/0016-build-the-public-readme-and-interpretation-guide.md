## Problem

The index will be misunderstood if the repository leads with implementation
details or leaves readers to infer what a high number means.

## Proposal

Make the README function as the front page of an economic indicator: one-line
question, current reading, historical chart, three-point interpretation,
formula, sources, limitations, and paths to the data and methodology. Add a
longer guide for responsible comparisons and commentary.

## Acceptance criteria

- [ ] The opening screen answers what PPG measures and shows the latest dated reading.
- [ ] A reading of 100 and movements above or below it are explained with examples.
- [ ] The difference between level, quarterly change, and annual change is clear.
- [ ] Non-claims and important limitations appear beside interpretation guidance.
- [ ] Data, methodology, provenance, reproduction, and citation links are easy to find.
- [ ] No prose implies that the median worker owns the represented portfolio.
