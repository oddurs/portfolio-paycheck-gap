# PPG Index v0.2.1

This patch corrects provenance weaknesses found in the v0.2.0 post-release
audit. The 187 index observations and latest PPG value are unchanged.

## Corrections

- Replaced the manually pinned v0.2.0 source timestamp with a newly acquired
  snapshot whose `retrieved_at` was recorded by the fetch operation.
- Separated source retrieval (`2026-09-18T02:57:09Z`) from artifact generation
  (`2026-09-18T02:57:21Z`) while keeping clean-checkout builds deterministic.
- Added verified, length-framed raw-bundle SHA-256 checksums. This removes the
  ambiguity in v0.2.0's multi-response BLS checksum construction.
- Retained unexpected revision candidates under `quarantine/` instead of
  discarding mutable upstream responses before review.
- Expanded CI to the declared Python boundary: 3.11 and 3.13.

The corrected source snapshot is **`2266e3ee4151567d`**. Its normalized inputs
are byte-identical to v0.2.0, so coverage remains **1979 Q1 through 2025 Q3**
and the latest PPG remains **4217.405914**. The reading is still stale because
BLS did not produce 2025 Q4 earnings.

## Assets and reproduction

The release bundles `ppg.csv`, `latest.json`, `ppg.svg`, `provenance.json`,
methodology v0.1, the schema-2 source manifest, checksum file, source archive,
and wheel. Run `make reproduce` in a clean checkout to rebuild and verify the
committed artifacts without network access.

All interpretation, source-proxy, population, revision, and noncommercial-use
limitations documented in [v0.2.0](v0.2.0.md) remain in force. In particular,
JKP-derived data and charts remain CC BY-NC 4.0, modified, and restricted to
noncommercial use.
